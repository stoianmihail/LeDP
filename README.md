# Truly Sub-$3^n$ Min-Sum Subset Convolution and Join Ordering

Building on Anthropic's [breakthrough](https://arxiv.org/abs/2610.06783) on multiple problem from fine-grained complexity (FGC), we show that min-sum subset convolution can also be solved in $O^*((3 - \varepsilon)^n)$-time. The algorithm uses the (now) subcubic min-plus matrix product. Since min-plus subset convolution is used as a primitive in _many_ problems (see some examples [here](https://arxiv.org/abs/2404.11364)), we show the first sub-$3^n$ speedup for our beloved problem in query optimization: join ordering. Before, a sub-$3^n$ algorithm was known only for the $C_{\mathrm{max}}$ cost function - now we also have a (theoretically) faster algorithm for $C_{\mathrm{out}}$. Note that it's highly non-intuitive that this was even possible. In fact, all the results in the aforementioned breakthrough paper are highly non-intuitive. Myself, and problably the whole FGC community, was simply in a shock.
